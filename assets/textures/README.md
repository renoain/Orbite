# Texture 3D

Berisi texture yang dipetakan ke sphere planet dan matahari saat rendering `three_dart`.

- Format: `.png` atau `.webp` (loslos), `.ktx2` bila memakai kompresi GPU.
- Resolusi: 1024x512 untuk planet, 2048x1024 untuk matahari.
- Warna tekstur planet berbasis peta NASA (domain publik), atributinya dicatat di `docs/content-source.md`.
- Texture dari repo pihak ketiga wajib dicek lisensinya lebih dulu.
- Ukuran besar: gunakan git-lfs atau sajikan lewat CDN.
