# Font

Berisi font yang dibundling di aplikasi, bukan font dari Google Fonts saat runtime.

- Format: `.ttf` atau `.otf`.
- Sumber: Google Fonts (lisensi OFL) atau font dengan lisensi permissive lain.
- Nama keluarga font harus sama dengan `family` di `pubspec.yaml`.
- Kalau cukup memakai `google_fonts` package, folder ini boleh dibiarkan kosong.
