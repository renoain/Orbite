# Aset Gambar

Berisi ilustrasi raster yang dipakai UI: slide onboarding, ilustrasi empty state, gambar planet versi ringan.

- Format: `.webp` untuk foto/ilustrasi, `.png` untuk yang butuh transparansi, `.svg` untuk ikon kustom.
- Target ukuran: ilustrasi layar penuh maksimal sekitar 500 KB agar unduhan app tetap ringan.
- Sumber dan lisensi dicatat di `docs/assets-inventory.md`.
