# Sumber Konten

## 1. NASA Solar System Exploration

- URL: https://solarsystem.nasa.gov/
- Digunakan untuk: Deskripsi planet, fakta unik, data atmosfer.

## 2. NASA Planetary Fact Sheet

- URL: https://nssdc.gsfc.nasa.gov/planetary/factsheet/
- Digunakan untuk: Data teknis (massa, radius, suhu).

## 3. NASA Lithograph Set

- URL: https://science.nasa.gov/resource/our-solar-system-lithograph-set/
- Digunakan untuk: Ringkasan fakta per objek.

## 4. Repo `Yczar/solar-system`

- URL: https://github.com/Yczar/solar-system
- Digunakan untuk: Kode rendering 3D (`three_dart`), tekstur planet.

## 5. NASA Space Place

- URL: https://spaceplace.nasa.gov/
- Digunakan untuk: Penjelasan musim, gerhana, dan fase Bulan dalam bahasa sederhana.
- Catatan: Halaman musim memakai penjelasan kemiringan sumbu Bumi; halaman gerhana menjelaskan umbra/penumbra.

## 6. NASA Eclipses

- URL: https://science.nasa.gov/eclipses/
- Digunakan untuk: Status dan penjelasan gerhana Matahari/Bulan.

## 7. Data Interior Planet

- Sumber: NASA Solar System Exploration dan NASA Planetary Fact Sheet (lihat bagian 1 dan 2).
- Digunakan untuk: Nama lapisan, kedalaman, suhu, dan komposisi.
- Catatan: Ketebalan lapisan pada scene 3D disederhanakan untuk visualisasi; bukan skala presisi.
- Catatan: Model gerhana mengasumsikan orbit Bulan sejajar bidang ekliptika (model ideal) dan diberi keterangan di layar.
