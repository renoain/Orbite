# Design System

## 1. Warna

- Primary: `#0B1D3A` (biru luar angkasa)
- Secondary: `#F5A623` (oranye matahari)
- Background: `#000000` (hitam)
- Text: `#FFFFFF` (putih)

## 2. Tipografi

- Font: `Poppins` (Google Fonts)
- Heading: 24sp, Bold
- Body: 14sp, Regular

## 3. Komponen

- **Tombol Utama**: Tinggi 48dp, radius 12dp, warna primary.
- **Card Planet**: Radius 16dp, shadow halus, padding 16dp.
- **Hotspot Interior**: Lingkaran 32dp, warna secondary, animasi pulse.

## 4. Prinsip Ergonomi (PDF hal 10)

- Tombol kontrol (Stop/Play, Fullscreen) di *Thumb Zone* bawah.
- Target sentuh minimal 48x48dp.
