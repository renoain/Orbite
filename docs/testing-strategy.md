# Strategi Pengujian

## 1. Unit Test (Laravel)

- Uji validasi trivia (jawaban benar/salah).
- Uji API Resource (memastikan field sensitif tidak bocor).

## 2. Widget Test (Flutter)

- Uji tombol Stop/Play mengubah state animasi.
- Uji navigasi dari Home ke Detail Planet.

## 3. Integration Test

- Uji alur: Login → Home → Klik Planet → Lihat Detail → Kembali.
